# Stop an N-Step Target at the Right Boundary

At a one-step horizon the target uses one reward and the next value. With a horizon spanning the rollout, it equals the bootstrapped return recurrence.

The later value trades an observed long-term sum for a prediction. This lesson isolates horizon and boundary mechanics rather than asserting a universally best horizon.
