# Project Mastery

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Confirmed in the supplied founding plan: Next.js App Router, TypeScript, pnpm workspaces, Monaco, Pyodide and NumPy, versioned YAML/Markdown/Python content. Static frontend with a separately hosted, sandboxed runner. Optional Supabase accounts belong to a later milestone.

## Users

Python programmers developing AI foundations and practical engineering skills. The founder leads product direction and delegates implementation to Codex.

## Product Purpose

Free, open-source practice that connects concepts, implementation, feedback, and integrated projects. Completion demonstrates practice, not independently verified certification or a job guarantee.

## Operating Context

First milestone: open Numerically Stable Softmax, edit Python, run tests, understand failures, retain a local draft. Desktop coding and responsive reading. No sign-up, paid API, or hosted GPU requirement.

## Capabilities and Constraints

MVP target: 12 exercises, three paths, and a mini retrieval system. The present milestone ships one complete exercise. Learner code must not access application credentials. Workers alone are not the isolation boundary. Content, reference solutions, schema, and runtime behavior require automated validation. Git and GitHub provide version control, review, and CI.

## Brand Commitments

Project Mastery is the working name, with no OpenAI affiliation. The user selected a dark workspace with restrained green accents. The supplied brief specifies readability, useful feedback, accessibility, and resizable editor panels.

## Evidence on Hand

The supplied founding conversation establishes scope and decisions. No user counts, learning outcomes, client names, or employment results have been demonstrated.

## Product Principles

Free learning; depth before quantity; browser/local computation; reproducible content; contributor-friendly architecture.

## Open Decisions

Public launch date, final brand, production hosting, and account synchronization remain later decisions.
