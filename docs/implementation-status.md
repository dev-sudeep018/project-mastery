# Connected learning release

Confirmed direction: 2,000 learning problems, approached through guided learning, project-first learning, and open exploration. The application supports understanding and building without a competitive coding queue.

The initial workspace is merged in PR #1. The connected-learning, curriculum, and production-workflow changes remain in the review stack beginning at PR #12. The 450-question expansion is on `codex/450-beginner-curriculum`, based on `codex/200-lesson-catalog`. See [verification](verification.md) for executed checks and [the expansion inventory](curriculum-450.md) for the new learning objectives.
